# LingoPath — E-Learning Website

LingoPath is a modern e-learning website designed to provide learners with an accessible and structured platform for exploring educational content and developing practical skills.

The project is built using **HTML5, CSS3, Bootstrap 5, and JavaScript**, with a focus on responsive design, clear navigation, interactive learning experiences, and a professional user interface.

## Introduction

**LingoPath** is an e-learning platform created to make online learning simple, organized, and accessible across different devices.

The platform provides a structured course catalog where learners can explore courses, view course information, access learning materials, and interact with different sections of the website.

The project demonstrates the use of modern front-end web development techniques, responsive layouts, reusable components, and JavaScript-based interactions.

## Features

* Responsive design for desktop, tablet, and mobile devices
* Structured course catalog
* Detailed course information and learning content
* Interactive lessons and learning sections
* User registration and login interfaces
* User authentication interface for personalized learning
* Instructor application form
* Contact form for user inquiries
* Course categories and filtering
* Responsive navigation and mobile menu
* Interactive JavaScript components
* Modern and accessible user interface

## Getting Started

### Prerequisites

Before running the project, make sure you have:

* A modern web browser such as Chrome, Firefox, Edge, or Safari
* A code editor such as Visual Studio Code
* Basic knowledge of HTML, CSS, and JavaScript

### Installation

1. Clone the repository:

```bash
git clone https://github.com/alyshahzad/LingoPath.git
```

2. Open the project folder in your preferred code editor.

3. Open `index.html` in your web browser.

You can also use the **Live Server** extension in Visual Studio Code for local development.

## Technologies Used

* **HTML5** — Website structure and semantic markup
* **CSS3** — Styling, layouts, animations, and responsive design
* **Bootstrap 5** — Responsive UI components and grid system
* **JavaScript** — Interactivity and dynamic functionality
* **Font Awesome** — Interface icons

## Responsive Design

LingoPath is designed to work across different screen sizes, including:

* Desktop computers
* Laptops
* Tablets
* Mobile phones

The interface adapts to different screen sizes to provide a consistent and user-friendly learning experience.
