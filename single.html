About this course

HTML is the foundation of the modern web. In this course, you will learn how HTML documents are structured, how elements and attributes work, and how to create well-organized web pages.

You will work with headings, paragraphs, links, images, lists, tables, forms and semantic HTML. The goal is not just to memorize tags, but to understand how they fit together when building real websites.

Skills you'll gain

Structure pages with HTML Work with semantic elements Create accessible forms Present data with tables Add links and media Write cleaner HTML

What you'll learn

Understand the structure of an HTML document.
Use headings, paragraphs, lists and links.
Add images and other media to pages.
Create tables for structured information.
Build practical HTML forms.
Use semantic HTML for better structure.
